# 尾座体机械加工工艺规程与夹具设计

机械制造技术基础课程设计：工艺路线拟定、工序卡编制与专用夹具设计

## 项目内容

针对**尾座体**零件，完成机械加工工艺设计与夹具设计：

- 零件工艺性分析
- 毛坯选择与加工余量确定
- 工艺路线拟定（工序、工步划分）
- 工序尺寸与公差计算
- 设备、刀具、量具选择
- 专用夹具结构设计
